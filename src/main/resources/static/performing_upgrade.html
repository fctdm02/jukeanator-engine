Performing JukeANator Upgrade

Step I: Backup Old Version (Program and Data):

  1. Open Programs, Accessories, Command Prompt to bring up a Command Prompt Window.
  2. Enter the following commands:
    1. C:
    2. CD \
    3. REN C:\kiosk C:\old_kiosk

Step II: Install New Version:

  1. Download /temp/kiosk.zip
  2. Open Programs, Accessories, Windows Explorer to bring up Windows Explorer.
  3. Navigate to where kiosk.zip was downloaded to (typically C:\Users\[your_user_id]\Downloads)
  4. Right-click on kiosk.zip and choose Extract All
  5. In the text field underneath Files will be extracted to this folder, replace the text that is there with just C:\
  6. De-select Show extracted files when complete, then click on Extract
  7. Wait a few minutes for files to be extracted to C:\kiosk

Step III: Copy data from Old Version to New Version:

  1. Switch back to the Command Prompt window from Step I
  2. Enter the following commands:
    1. COPY C:\old_kiosk\JukeANator.CTL C:\kiosk
    2. COPY C:\old_kiosk\AdminPwd.CTL C:\kiosk
    3. COPY C:\old_kiosk\OwnerPwd.CTL C:\kiosk
    4. COPY C:\old_kiosk\JukeANator.properties C:\kiosk
    5. COPY C:\old_kiosk\JukeANator.DAT C:\kiosk
    6. COPY C:\old_kiosk\CDStats.TXT C:\kiosk
    7. COPY C:\old_kiosk\Acceptor.DAT C:\kiosk

Step IV: Running New Version:

  1. Switch back to the Command Prompt window from Step I
  2. Enter the following commands:
    1. CD C:\kiosk
    2. GO
NOTE: If you had JukeANator configured in the Windows registry to automatically run at startup, it will continue to do so...
